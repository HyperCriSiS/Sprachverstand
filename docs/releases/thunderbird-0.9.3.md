# Sprachverstand 0.9.3 für Thunderbird

Diese Version übernimmt die Verbesserungen der Browser-Ausgabe.

- Die Überschrift für weitere Korrekturbereiche heißt jetzt „Wo soll außerdem korrigiert werden?“.
- Das Popup kann auf Wunsch direkt mit der Liste der Korrekturen starten.
- Die Ersetzungsübersicht zeigt Paarformen wie „der / die Nutzer*in“ vollständig.
- Zitate, Namen und technische Angaben sind zuverlässiger geschützt.
